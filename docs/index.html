Unit 3 CAD hub

3D models, engineering drawings and short animations for T Level Engineering, Unit 3 Engineering representations (City and Guilds 8730, criteria 3.1 and 3.2). Every drawing on this site is made from the same CAD model, so the views always agree.

Using the hub in a lesson

3D viewer: open a model, then use the view buttons to jump between the isometric view, the front view, the plan and the end views. Ask learners to sketch each view before you click to it. Tick Section A-A to cut the part in half, or drag Explode to pull an assembly apart.

Build steps (Inventor): open the Build steps tab in the viewer to rebuild a model one stage at a time. Each step names the Autodesk Inventor command, where it is on the ribbon and what to click and type. The 3D model shows the part as it stands after that step, with the material the step adds in amber and the material it cuts away in red. Use the arrow keys or Next step to move on.

Drawings: each model has a third angle sheet and a first angle sheet (front view, plan, end view, isometric, centre lines, hidden detail and an ISO 7200 style title block), and a section A-A sheet where a section is useful. The SVG files can be edited; the PNG files print well.

Animations: short silent MP4 clips (a turntable spin, the move from isometric into each view, the exploded view and the section cut). They play in PowerPoint and Teams.

Downloads: STEP files open in Fusion, Inventor, SolidWorks, Onshape and FreeCAD. STL files are for 3D printing or quick viewing.

Models written in CadQuery (Python). Drawings use hidden line removal from the same models. Viewer uses three.js (MIT licence). Dimensions in millimetres.
